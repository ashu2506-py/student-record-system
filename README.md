# 🎓 Student Record Management System

A powerful and user-friendly **console-based Student Record Management System** built with **Python 3**.  
This project demonstrates core programming concepts like **CRUD operations, input validation, exception handling, modular programming, and formatted console output**.

---

## ✨ Features

✅ Add New Student Records  
✅ View All Student Records in Tabular Format  
✅ Search Students by Roll Number  
✅ Update Student Marks Dynamically  
✅ Delete Student Records with Confirmation  
✅ Automatic Total & Percentage Calculation  
✅ Robust Input Validation & Error Handling  
✅ Clean and Modular Function-Based Code Structure

---

## 🛠️ Technologies Used

- Python 3
- Standard Python Libraries Only
